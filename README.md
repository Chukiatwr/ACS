# Applied Computer Science @ KMUTT multi-page website prototype

This static website is self-contained. Open `index.html` in a browser.

## Structure
- `index.html` — landing page
- `program.html` — formal programme identity and outcomes
- `study.html` — 4-year learning journey and curriculum structure
- `projects.html` — CSS 491–492 senior project summary and domains from Excel sheets 1 and 3
- `wil.html` — CSS 495 Work-Integrated Learning information and anonymized industry partner profiles
- `people.html` — faculty profiles using images extracted from Faculty.pptx
- `research.html` — faculty research profiles and expertise areas
- `student-life.html` — student support and activities
- `admissions.html` — applicant-oriented overview

## Privacy rule applied
Real company names are not displayed in Industry Partner sections. Partners are described by industry sector and organization scale instead.
